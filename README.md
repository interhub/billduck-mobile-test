# 🦆 BillDuck: импорт банковской выписки без потери состояния

📱 Фрагмент мобильного приложения на React Native (Expo SDK 57). Человек выбирает выписку в PDF или CSV, телефон проверяет файл и отправляет его на локальный тестовый сервер, ждёт обработки и показывает регулярные платежи с суммой в месяц.

🛡️ Приложение переживает потерянный ответ, перезапуск и выключенный сервер. Второго задания на сервере не появляется, а «Удалено» на экране бывает только после подтверждения сервера.

## 🧰 Что нужно на Mac

- 🟢 Node.js 22 (проверено на 22.22) и npm 10.
- 🍏 Xcode 27.0 с симулятором iOS 27 и CocoaPods 1.17: только для сборки iOS из исходников.
- 🤖 Android SDK с platform 36 и build-tools 36.0.0, эмулятор с Android 15 (API 35), JDK 17: только для сборки Android из исходников.
- 📦 Для готовых сборок хватит Node.js, симулятора iPhone и эмулятора Android.

## ⚡ Быстрая проверка на готовых сборках

1. 📂 Распаковать архив:

```bash
unzip billduck-mobile-test.zip && cd billduck-mobile-test
```

2. 🔌 Запустить тестовый сервер в отдельном окне терминала. Он слушает `http://127.0.0.1:8787` и хранит состояние в файле, поэтому переживает свой перезапуск:

```bash
npm run mock
```

3. 📄 Запустить симулятор iPhone и эмулятор Android, затем положить фикстуры туда, где их видит системный выбор файла:

```bash
scripts/push-fixtures.sh
```

🗃️ Скрипт кладёт `statement.csv`, `statement.pdf`, `spoofed.pdf`, `oversize.csv`, копию выписки под именем `Выписка за октябрь 🦆.csv`, пустой файл и CSV с переносами `\r\n` и с BOM. На iOS файлы появляются в «Файлы → На iPhone», на Android в «Загрузках».

4. 🍏 iOS: симулятор ходит на сервер Mac напрямую.

```bash
unzip -o builds/BillDuck-simulator.zip -d builds
xcrun simctl install booted builds/BillDuck.app
xcrun simctl launch booted com.billduck.app
```

5. 🤖 Android: внутри эмулятора `127.0.0.1` - это сам эмулятор, поэтому порт сервера пробрасывается через `adb reverse`. После перезапуска эмулятора команду надо повторить.

```bash
adb reverse tcp:8787 tcp:8787
adb install -r builds/billduck-release.apk
adb shell am start -n com.billduck.app/.MainActivity
```

## 🛠️ Запуск из исходников

```bash
npm ci
```

🍏 iOS: команда создаёт папку `ios/`, ставит поды, собирает отладочную сборку и запускает Metro.

```bash
npx expo run:ios
```

🤖 Android: обычный HTTP приложению разрешён только к `127.0.0.1` и `localhost`, поэтому отладочная сборка берёт JS у Metro через `localhost`. Эмулятору надо подсказать этот адрес и пробросить порты. `adb root` работает на образах эмулятора с Google APIs.

```bash
adb root && adb wait-for-device
adb shell setprop metro.host localhost
adb reverse tcp:8081 tcp:8081
adb reverse tcp:8787 tcp:8787
npx expo run:android
```

🧩 На образе с Google Play `adb root` запрещён. Тогда подойдёт release-вариант: JS уже внутри сборки, Metro не нужен, остаётся только порт сервера.

```bash
adb reverse tcp:8787 tcp:8787
npx expo run:android --variant release
```

## 🎛️ Сценарии сервера

📲 На главном экране внизу ссылка «Диагностика». На этом экране адрес и доступность сервера, переключатель сценариев (`happy`, `lost_ack`, `stale_status`, `delete_failure`), счётчики сервера, состояние операции на телефоне, журнал ответов и «Сбросить всё»: кнопка сбрасывает и сервер, и телефон.

💻 То же командами:

```bash
curl -X POST http://127.0.0.1:8787/__test/scenario -H 'Content-Type: application/json' -d '{"mode":"lost_ack"}'
curl http://127.0.0.1:8787/__test/state
curl -X POST http://127.0.0.1:8787/__test/reset
```

🔁 `/__test/reset` возвращает сценарий `happy` и начинает нумерацию заданий заново с `job-demo-001`.

## 🧭 Где что в коде

- 🔄 `src/services/importController/`: контроллер импорта. Отправка, восстановление по ключу, опрос, удаление, уборка отменённых загрузок и хранение операции.
- 🧠 `src/utils/import/`: чистый редьюсер фаз, защита ревизий и лента ответов сервера.
- 🌐 `src/api/importsApi/`: запросы к серверу, у каждого свой таймаут и проверка ответа.
- 📁 `src/utils/files/`: проверка размера и первых байтов файла, сгенерированные имена, временные копии.
- 📱 `src/screens/`: экраны; `src/components/ui/`: общие компоненты.
